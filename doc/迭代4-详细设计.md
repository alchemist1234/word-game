## 1. 概述

### 1.1 目标
接入用户系统（认证 + JWT），实现单人闯关：章节地图、关卡、5 种目标类型、星级评价、进度持久化、词库图鉴雏形。

### 1.2 可运行状态
H5 手机号登录（验证码 mock）后进入章节地图，玩 3 章（前 2 章 4×4、第 3 章 5×5），每关有目标（分数/词数/成语/限时/指定词），完成获 1-3 星，进度与图鉴持久化到后端。

### 1.3 范围
- **In**：users/user_auths 表、JWT 认证（H5 手机号 mock + 微信 mock）、关卡配置（3 章 × 5 关 MVP）、闯关 API、user_progress 表、章节地图页、关卡目标 UI、星级结算、图鉴雏形（user_found_words 落库 + 列表页）
- **Out**：无 Boss 关（迭代 5）、无道具（迭代 8）、无对战、真实微信登录需 appid（技术债）、真实短信网关（技术债 #7）

### 1.4 对齐 GDD
- §4.1 单人闯关（章节/关卡/目标/星级）、§4.1.4 主题章节、§5.4 词库图鉴、§7.4.1/7.4.2 用户表、§7.5 统一账号

## 2. 用户系统设计

### 2.1 数据模型（PostgreSQL）

#### 2.1.1 `users` 用户表（对齐 GDD §7.4.1）

```sql
CREATE TABLE users (
  id            BIGSERIAL PRIMARY KEY,
  phone         VARCHAR(20) UNIQUE,          -- 跨端账号合并主键
  nickname      VARCHAR(64),
  avatar        TEXT,
  level         INT DEFAULT 1,
  exp           INT DEFAULT 0,
  rank_tier     SMALLINT DEFAULT 1,
  rank_score    INT DEFAULT 0,
  coins         INT DEFAULT 0,
  diamonds      INT DEFAULT 0,
  stamina       INT DEFAULT 5,
  stamina_updated_at TIMESTAMPTZ DEFAULT now(),
  chapter_current INT DEFAULT 1,
  created_at    TIMESTAMPTZ DEFAULT now()
);
```

#### 2.1.2 `user_auths` 多端账号绑定（对齐 GDD §7.4.2）

```sql
CREATE TABLE user_auths (
  id         BIGSERIAL PRIMARY KEY,
  user_id    BIGINT NOT NULL REFERENCES users(id),
  platform   VARCHAR(32) NOT NULL,   -- h5 / wechat_mp / ...
  openid     VARCHAR(128) NOT NULL,  -- 平台内唯一（H5 用手机号，微信用 openid）
  unionid    VARCHAR(128),
  created_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(platform, openid)
);
```

#### 2.1.3 `user_progress` 闯关进度

```sql
CREATE TABLE user_progress (
  id          BIGSERIAL PRIMARY KEY,
  user_id     BIGINT NOT NULL REFERENCES users(id),
  level_id    VARCHAR(16) NOT NULL,   -- 如 "1-1"
  stars       SMALLINT DEFAULT 0,     -- 0-3
  best_score  INT DEFAULT 0,
  completed   BOOLEAN DEFAULT FALSE,
  updated_at  TIMESTAMPTZ DEFAULT now(),
  UNIQUE(user_id, level_id)
);
```

#### 2.1.4 `user_found_words` 图鉴（对齐 GDD §5.4）

```sql
CREATE TABLE user_found_words (
  id             BIGSERIAL PRIMARY KEY,
  user_id        BIGINT NOT NULL REFERENCES users(id),
  word           VARCHAR(16) NOT NULL,
  rarity         VARCHAR(8) NOT NULL,
  found_count    INT DEFAULT 1,
  first_found_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(user_id, word)
);
```

### 2.2 认证流程（对齐 GDD §7.5）

```
客户端(某端) -> 平台登录取凭证
  H5: 手机号 + 验证码（mock，验证码固定 "1234" 或控制台输出）
  微信小程序: wx.login -> code（mock：code 直接当 openid）

-> POST /auth/login { platform, credential }
  credential: H5={phone, code}; 微信={code}

后端：
  1. 验证凭证
     H5: 校验验证码（mock：固定 "1234" 或内存缓存）
     微信 mock: code 当 openid（无真实 code2session，技术债）
  2. 查 user_auths(platform, openid)
     - 已存在 -> 取 user_id
     - 不存在 -> 新建 user + user_auths
  3. 签发 JWT { userId, platform }
  4. 返回 { token, user: {id, nickname, chapterCurrent} }
```

### 2.3 JWT（@nestjs/jwt）

- 登录签发：`jwtService.sign({ userId, platform })`，过期 7 天
- 验证 Guard：`JwtAuthGuard`（手动实现，从 Authorization header 取 Bearer token，验证，注入 req.user = { userId }）
- 保护路由：闯关/图鉴/进度 API 加 `@UseGuards(JwtAuthGuard)`
- game API（/game/word）也加 Guard（拿 userId 更新图鉴）

### 2.4 认证 API

```
POST /auth/login
  Req: { platform: 'h5'|'wechat_mp', credential: H5{phone,code} | 微信{code} }
  Resp: { token: string, user: { id, nickname, chapterCurrent } }

POST /auth/sms-code   // H5 发送验证码（mock）
  Req: { phone }
  Resp: { sent: true }   // mock：验证码固定 "1234"，控制台打印

GET /auth/me   // 获取当前用户（需 JWT）
  Resp: { id, nickname, chapterCurrent, coins, ... }
```

## 3. 闯关系统设计

### 3.1 关卡配置（data/levels.json）

3 章 × 5 关 MVP（可扩到 10 关/章）。结构：

```json
[
  {
    "id": "1-1",
    "chapter": 1,
    "level": 1,
    "title": "初识字海",
    "size": 4,
    "difficulty": "easy",
    "objective": { "type": "score", "target": 20 },
    "stars": [20, 35, 50],
    "duration": 90
  },
  {
    "id": "1-3",
    "chapter": 1,
    "level": 3,
    "title": "成语初探",
    "objective": { "type": "idiom", "target": 1 },
    "stars": [1, 2, 3]
  },
  {
    "id": "2-4",
    "chapter": 2,
    "level": 4,
    "title": "限时挑战",
    "objective": { "type": "timeLimit", "target": 60, "score": 40 },
    "stars": [40, 55, 70]
  },
  {
    "id": "3-2",
    "chapter": 3,
    "level": 2,
    "title": "春意盎然",
    "size": 5,
    "difficulty": "standard",
    "objective": { "type": "specificWord", "char": "春", "target": 2 },
    "stars": [2, 3, 4]
  }
]
```

### 3.2 关卡目标类型（对齐 GDD §4.1.2）

| type | objective 字段 | 达成判定 | actualValue |
|---|---|---|---|
| score | {target} | 总分 >= target | score |
| wordCount | {target} | 找到词数 >= target | foundWords.length |
| idiom | {target} | 成语数 >= target | idiomCount |
| timeLimit | {target(秒), score} | target 秒内分数 >= score | score（限时内） |
| specificWord | {char, target} | 含 char 的词数 >= target | matchCount |

> Boss 关（vs AI）留迭代 5，本迭代不实现。

### 3.3 星级计算

每关 `stars: [1星阈值, 2星, 3星]`。结算时算 `actualValue`，比较：

```
stars = actualValue >= stars[2] ? 3 : actualValue >= stars[1] ? 2 : actualValue >= stars[0] ? 1 : 0
```

- 0 星：未达成（不算通关，不写进度或写 0 星）
- 1-3 星：通关，写 user_progress（取最高星）

### 3.4 闯关 API

#### `GET /chapters`（需 JWT）

返回章节 + 关卡 + 当前用户进度：

```json
{
  "chapters": [
    {
      "chapter": 1,
      "title": "初识字海",
      "unlocked": true,
      "levels": [
        { "id": "1-1", "title": "...", "stars": 3, "unlocked": true },
        { "id": "1-2", "stars": 1, "unlocked": true },
        { "id": "1-3", "stars": 0, "unlocked": true }
      ]
    }
  ],
  "currentChapter": 1
}
```

解锁规则：第 1 章第 1 关默认解锁；通关一关（≥1 星）解锁下一关；通关一章所有关解锁下一章。

#### `POST /level/start`（需 JWT）

```json
// Req
{ "levelId": "1-1" }

// Resp
{
  "matchSessionId": "uuid",
  "grid": [["中","国",...],...],
  "size": 4,
  "duration": 90,
  "objective": { "type": "score", "target": 20 },
  "stars": [20, 35, 50],
  "title": "初识字海"
}
```

内部：取关卡配置 -> 调 `gameService.getGrid(difficulty)` -> 会话加 `levelId/objective/isLevelMode` -> 返回网格 + 目标。

指定词关（specificWord）：生成网格后**注入指定字**（随机替换一个非目标词格子为指定字），保证网格含该字。

#### `POST /level/submit`（需 JWT）

```json
// Req
{ "matchSessionId": "uuid" }

// Resp
{
  "score": 45,
  "stars": 2,
  "maxCombo": 4,
  "comboScore": 3,
  "potentialCount": 18,
  "objectiveMet": true,
  "foundWords": [...],
  "newUnlocked": ["1-4"]   // 新解锁的关卡（如有）
}
```

内部：读会话（levelId/objective）-> 调 endGame 逻辑（算 score/foundWords/maxCombo）-> 算 actualValue + 星级 -> upsert user_progress（取最高星）-> 更新图鉴（user_found_words）-> 算新解锁 -> 返回。

#### 提词复用 `POST /game/word`（需 JWT）

不变，但加 JWT Guard 拿 userId。成功找词时 upsert user_found_words（图鉴收集）。

### 3.5 会话扩展（Redis）

`match_session:{sid}` Hash 增加：
- `levelId`：关卡 ID（闯关模式）
- `objective`：JSON string（关卡目标）
- `isLevelMode`：'1'（闯关）/ '0'（自由模式）

GET /pokedex（需 JWT）
  Resp: {

## 5. 前端设计

### 5.1 新增页面

| 页面 | 路径 | 说明 |
|---|---|---|
| 登录页 | pages/Login/index | 手机号+验证码（H5）|
| 章节地图 | pages/Chapters/index | 章节+关卡节点+星级 |
| 图鉴 | pages/Pokedex/index | 已收集词列表 |

### 5.2 路由与导航流

```
App 启动
  -> 检查 token（localStorage）
     - 无 token -> Login
     - 有 token -> 验证 /auth/me
        - 失效 -> Login
        - 有效 -> Chapters

Login -> 登录成功存 token -> Chapters

Chapters -> 点关卡 -> Game（levelMode）
Game -> 结束 -> Result（星级）-> Chapters（返回）
Chapters -> 图鉴入口 -> Pokedex -> 返回 Chapters
```

pages.json 调整：Login 设为首页（或 App 启动逻辑判断）。

### 5.3 登录页（pages/Login/index）

- 手机号输入 + 验证码输入 + "获取验证码"按钮
- 调 /auth/sms-code（mock）+ /auth/login
- 登录成功存 token + 跳 Chapters
- 极简样式

### 5.4 章节地图页（pages/Chapters/index）

- 章节列表（纵向），每章显示关卡节点（横向或网格）
- 关卡节点：标题 + 星级（★★★）+ 锁状态
- 已解锁可点 -> Game（传 levelId）
- 未解锁灰色 + 锁图标
- 顶部：用户信息（昵称）+ 图鉴入口

### 5.5 Game 页扩展（关卡模式）

- 顶部加**关卡目标**显示：`目标：得到 20 分（当前 15）`
- 目标进度实时更新（根据 objective type）
- 倒计时：限时关用 objective.target 秒；其他用关卡 duration
- store 加 levelMode + objective + levelId

### 5.6 Result 页扩展（星级）

- 顶部大字显示星级（★ ×N）
- 目标达成/未达成提示
- "下一关"按钮（解锁的下一关）/ "重玩" / "返回章节"
- 保留：总分、词列表、最高连击、覆盖率、连击得分

### 5.7 store 扩展（client/src/store/game.ts）

新增状态：
- `levelMode: boolean`
- `levelId: string`
- `objective: object | null`
- `stars: number[]`
- `lastStars: number`

Actions：
- `startLevel(levelId)`：调 /level/start，设 levelMode + objective
- `submitLevel()`：调 /level/submit，设 lastStars
- 区分自由模式（startGame）vs 闯关模式（startLevel）

### 5.8 请求拦截器（client/src/api/index.ts）

- 所有请求自动加 `Authorization: Bearer {token}`（从 storage 读）
- 401 响应 -> 清 token + 跳 Login
