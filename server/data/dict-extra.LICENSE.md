# dict-extra 数据来源

`dict-extra.json` 是面向本项目 2 万词筛选集的释义补充包：

- 基础来源：CC-CEDICT / mdbg Chinese dictionary，原始数据采用 [CC BY-SA 3.0](http://creativecommons.org/licenses/by-sa/3.0/) 许可。
- 成语补充：`chinese-idiom-chengyu`（MIT，数据致谢 chinese-xinhua）。
- 用途：词库图鉴释义字段；只保存筛选后的词条，不将完整词典打包进服务。
- 若正式发布，请在上线页面按各自许可证要求保留署名并提供许可证链接。
